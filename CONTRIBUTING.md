# Contributing to MVCS

Thank you for your interest in contributing to the Mechanic Virtual Conversational System!

## 🤝 How to Contribute

### Reporting Bugs

1. Check if the bug has already been reported in [Issues](https://github.com/Akashb101/mvcs-mechanic-system/issues)
2. If not, create a new issue with:
   - Clear title and description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable
   - Environment details (OS, Node version, etc.)

### Suggesting Features

1. Check existing [Issues](https://github.com/Akashb101/mvcs-mechanic-system/issues) for similar suggestions
2. Create a new issue with:
   - Clear feature description
   - Use case and benefits
   - Possible implementation approach

### Code Contributions

1. **Fork the repository**
2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**
   - Follow existing code style
   - Add tests if applicable
   - Update documentation
4. **Commit your changes**
   ```bash
   git commit -m "Add: brief description of changes"
   ```
5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Create a Pull Request**

## 📝 Code Style

### Backend (JavaScript)
- Use ES6+ features
- 2 spaces for indentation
- Semicolons required
- Descriptive variable names
- Comments for complex logic

### Frontend (React)
- Functional components with hooks
- 2 spaces for indentation
- PropTypes or TypeScript (future)
- Component-level comments

### Database
- Snake_case for table/column names
- Descriptive names
- Foreign keys properly indexed

## 🧪 Testing

- Write tests for new features
- Ensure existing tests pass
- Aim for 80%+ code coverage

```bash
# Run tests
npm test
```

## 📚 Documentation

- Update README.md if needed
- Add JSDoc comments for functions
- Update API.md for new endpoints
- Include examples

## 🔍 Code Review Process

1. Maintainer reviews PR
2. Feedback provided if needed
3. Changes requested or approved
4. Merged into main branch

## 🎯 Priority Areas

Current focus areas for contributions:

1. **Testing** - Unit and integration tests
2. **Mobile Responsiveness** - Frontend improvements
3. **Documentation** - Examples and tutorials
4. **Bug Fixes** - See open issues
5. **Performance** - Optimization opportunities
